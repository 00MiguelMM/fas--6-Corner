# GymFlow

GymFlow es una aplicación móvil desarrollada con React Native y Expo para organizar entrenamientos, rutinas y objetivos relacionados con el gimnasio.

## Tecnologías principales

- React Native
- Expo
- TypeScript
- Expo Router
- Zustand
- FlashList
- AsyncStorage
- Zod

## Funcionalidades principales

- Gestión de rutinas de entrenamiento
- Registro de entrenamientos
- Objetivos y notas fitness
- Navegación por pestañas
- Persistencia local de datos
- Soporte para modo oscuro y claro
