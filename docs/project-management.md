# Gestión del proyecto

Para organizar el desarrollo de GymFlow estoy utilizando Trello como herramienta de gestión de tareas.

El tablero está dividido en cinco columnas principales:

- Backlog
- Todo
- In Progress
- Review
- Done

Cada funcionalidad principal de la aplicación tiene su propia tarjeta. Además, las tareas grandes se dividen en subtareas técnicas más pequeñas para facilitar el seguimiento del trabajo.

A medida que avanzo en el desarrollo, voy moviendo las tarjetas entre columnas según el estado de cada funcionalidad.

Esta organización me permite tener una visión más clara del progreso del proyecto y priorizar mejor las tareas pendientes.
